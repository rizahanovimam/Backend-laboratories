## Теоретическое обоснование

**Бэкенд-разработка** — это создание серверной части веб-приложений, которая обрабатывает запросы клиентов, взаимодействует с базами данных, выполняет бизнес-логику и формирует ответы. Бэкенд работает на сервере и не виден пользователю напрямую.

**Клиент-серверная архитектура** строится на модели взаимодействия, где клиент (браузер, мобильное приложение) отправляет HTTP-запросы, а сервер (бэкенд-приложение) их обрабатывает и возвращает HTTP-ответы.

**Эндпоинт (endpoint)** — это конкретный URL-адрес вместе с методом HTTP, по которому клиент обращается к серверу для получения ресурса. Например: `GET /api/users`.

**JSON (JavaScript Object Notation)** — текстовый формат обмена данными, ставший стандартом де-факто для REST API благодаря своей простоте и удобочитаемости.

## Контрольные вопросы

**1. Что такое клиент-серверная архитектура?**

Это модель взаимодействия, где клиент отправляет запросы, а сервер их обрабатывает и возвращает ответы.


**2. Какой протокол используется для общения клиента и сервера в вебе?**

Протокол HTTP (HyperText Transfer Protocol).


**3. Что такое эндпоинт (endpoint)?**

Это конкретный URL + метод HTTP, по которому клиент обращается к серверу. Пример: `GET /api/users`.


**4. Какую структуру имеет HTTP-запрос и HTTP-ответ? Что такое код состояния?**

**HTTP-запрос:** стартовая строка, заголовки, тело.  
**HTTP-ответ:** стартовая строка, заголовки, тело.

**Код состояния** — трёхзначное число, показывающее результат запроса:
- 2xx — успех
- 4xx — ошибка клиента
- 5xx — ошибка сервера

**5. Что такое JSON? Почему он популярен?**

JSON — текстовый формат обмена данными. Популярен из-за простоты, лёгкости парсинга и поддержки всеми языками программирования.

**6. Как запустить сервер на Node.js или Flask?**

**Node.js:** `npm run dev`  
**Flask:** `python app.py`

**7. Что такое автоматический перезапуск и зачем он нужен?**

Это автоматическая перезагрузка сервера при изменении кода. Экономит время разработчика.

**Для Node.js используется пакет nodemon.**

**8. Какие коды состояния HTTP вы знаете?**

- 200 — OK
- 404 — Not Found (ресурс не найден)
- 500 — Internal Server Error

**9. Что такое middleware в Express / декораторы во Flask?**

Это функции, которые выполняются между запросом и ответом. Используются для логирования, аутентификации, обработки ошибок.

**10. Как получить параметр из URL в вашем фреймворке?**

**Express:** `req.params.id`  
**Flask:** параметр в функции `get_user(user_id)`
